# Engineering Task Contract

## Intent

Describe the observable outcome that should become true.

## Success Criteria

Define conditions that must hold after execution.

## Constraints

Define boundaries the agent must preserve.

## Evidence

Identify authoritative information that should ground decisions.

## Verification

Define the evidence required before claiming completion.

## Non-goals

Identify nearby work that should not be performed.

## Completion Report

Report:

- changes made;
- evidence gathered;
- verification performed;
- unresolved uncertainty;
- failures or checks that could not be completed.
